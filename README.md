# OpenWRT Lite Stats

A lightweight, modern, and responsive LuCI status module for OpenWRT — designed to show essential real-time system and network statistics with a stylish interface.

## ✨ Features

- Real-time upload & download speed (per second)
- Total upload & download traffic
- Public IP & ISP info
- Beautiful card layout with responsive mobile support
- Lightweight and optimized for low-resource devices
- Animated UI elements and toggles
